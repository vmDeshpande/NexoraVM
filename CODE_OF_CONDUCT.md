# Code of Conduct

## Our Standard

We want NexoraVM to be a respectful, technically rigorous, and welcoming project. Participants are expected to:

- Be respectful and assume good faith.
- Focus criticism on ideas, code, and behavior rather than people.
- Explain technical disagreement clearly and constructively.
- Welcome different experience levels and backgrounds.
- Protect private information and avoid sharing secrets or personal data.

## Unacceptable Behavior

Unacceptable behavior includes harassment, discrimination, intimidation, personal attacks, deliberate disruption, unwanted contact, sexualized conduct, publishing private information, and any other conduct that would be inappropriate in a professional technical community.

## Enforcement Responsibilities

Repository maintainers are responsible for clarifying and enforcing this standard, addressing reported concerns fairly, and taking proportionate action when needed. Actions may include a correction request, content removal, temporary restriction, or permanent exclusion from project spaces.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, project communication, and other spaces where a person represents NexoraVM.

## Reporting

A dedicated private reporting channel has not yet been configured. Report concerns to repository maintainers through an available private GitHub mechanism when possible. Do not disclose sensitive personal or security information publicly.

## Attribution

This document is adapted from the structure and principles of the Contributor Covenant. It is intentionally concise for this repository and does not create a separate legal policy.
